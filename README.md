
# 🖥️ Escalonador de Processos - Sistemas Operacionais

## 📋 Descrição  

Este projeto foi desenvolvido na disciplina Sistemas Operacionais e implementa um escalonador de processos na linguagem Java. O objetivo do projeto é simular a execução de processos no sistema operacional, aplicando diferentes algoritmos de escalonamento.

O escalonador gerencia o tempo de CPU alocado para os processos, gerando relatórios com base nos algoritmos de escalonamento implementados. 

## 🛠️ Tecnologias Utilizadas  

- ☕ **Java**: Linguagem de programação para implementação do projeto.
